# SecurePassGuard 🔐

A lightweight web application that helps users analyze and improve their password strength. It provides instant feedback, visual indicators, and suggestions for creating stronger passwords to promote better cybersecurity habits.

---

## 🚀 Features
- Real-time password strength analysis  
- Visual strength meter (Weak, Moderate, Strong)  
- Suggestions for creating stronger passwords  
- Optional password generator  
- Responsive and user-friendly interface  

---

## 🛠️ Technologies Used
- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsiveness  
- **JavaScript (ES6)** – Logic and interactivity  

---

   ```bash
   git clone https://github.com/<your-username>/SecurePassGuard.git

   2 Navigate to the project directory:
   cd SecurePassGuard

💡 Usage
Enter a password in the input field.

Click Check Strength to see feedback.

Use the Generate Password option for secure suggestions.
